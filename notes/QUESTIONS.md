# Open Architectural Questions (`QUESTIONS.md`)

All foundational architectural questions for Wave 0, Wave 1, Wave 1.5, and the Three-Tier Hybrid Architecture for Waves 2–5 have been resolved and recorded in [`notes/DECISIONS.md`](./DECISIONS.md):

1. **Target Language & Pilot Scope (`DECISIONS #1`)**: Wave 1 Dual-Track (`crates/` Safe Rust + `src/flexmesa/` Python/JAX `float64`) covering all 8 foundational numerical modules (`const`, `utils`, `math`, `auto_diff`, `interp_1d`, `interp_2d`, `mtx`, `num`) plus stateless Tier 3/5 microphysics modules `neu` and `turb`.
2. **Legacy & External Bundled Subsystem Exclusions (`DECISIONS #2`)**: Exclude `pgstar`/`pgbinary` (`#3`), external `stella`/`adipls`/`gyre` source ports (`#4`), and legacy `RSP1` (`#5`), replacing `pgstar` with Python/Matplotlib diagnostics, exporting `GYRE`/`FGONG` structures at the pulsation boundary, and porting unified `TDC`/`RSP2`.
3. **Physics Data Tables & 7-Component EOS Staging (`DECISIONS #3`)**: Convert MESA tables in Wave 0 into 64-byte-aligned `float64` `.safetensors` files (`mmap`-ready in `~/.cache/flexmesa/data/`), distributed as modular `.safetensors.zst` bundles on GitHub Release Assets with a committed `SHA-256` manifest, and stage `eos` into Wave 3a (`Ideal + HELM + PC + Skye`) and Wave 3b (`FreeEOS + OPAL/SCVH + CMS`).
4. **Repository License & Portable Configuration (`DECISIONS #4`)**: License `FlexMESA` under `LGPL-3.0-or-later` and keep build/test configuration portable across platforms.
5. **Issue-First Decomposition & Pre-Merge Gate (`DECISIONS #5`)**: Decompose waves into linked sub-issues and enforce automated tests, static analysis, code simplification, and multi-lens code review before merging.
6. **Integrated Three-Tier Hybrid Architecture (`DECISIONS #6`, [Issue #26](https://github.com/joshspeagle/FlexMESA/issues/26))**: Consolidate Tier A infrastructure (`utils`, `schema`, `data`, `testing`) and explicit `auto_diff` hyperdual types in Safe Rust exposed via `PyO3` (`flexmesa._rust`), prune redundant pure-Python parser/dual-number loops, and pair monomorphized Safe Rust + `rayon` CPU physics kernels with branchless `@jax.jit` flat-array kernels behind `backend="auto" | "rust" | "jax"`.
7. **Coupled Linear & Stiff Solver Strategy (`DECISIONS #7`, [Issue #26](https://github.com/joshspeagle/FlexMESA/issues/26))**: Provide both Hirshman `bcyclic` odd-even cyclic reduction in Safe Rust (`crates/flexmesa-mtx`) and two JAX solver pathways (`solver_mode="pcr"` native $\lceil \log_2 N_{\mathrm{zones}} \rceil$ parallel cyclic reduction on GPU and `solver_mode="rust_ffi"` calling `flexmesa._rust` with an analytical `jax.custom_vjp` rule).
8. **Standing `Wave X.5` Consolidation, Upstream Fortran MESA Gate & Public MkDocs Material Website (`DECISIONS #8`, [Issue #28](https://github.com/joshspeagle/FlexMESA/issues/28))**: Conclude every wave with a dedicated `Wave X.5` holistic code review, optimization loop, compiled upstream Fortran MESA parity and timing verification gate (`benchmarks/fortran_mesa/`), and incremental update of the public MkDocs Material documentation website (`mkdocs.yml`, `docs/`).
