# Notes

What each document here is for, and whether it is kept current.

| Document | What it is | Kept current by |
| :-- | :-- | :-- |
| [`SCOPE.md`](SCOPE.md) | What is ported, in what order, and the `v0.1.0` definition | the project lead's decisions |
| [`DECISIONS.md`](DECISIONS.md) | Decisions in force, with an index of every numbered decision | each pull request that makes a decision |
| [`audit/case_table.md`](audit/case_table.md) | Status of every upstream test case | generated by `flexmesa harness table`; never edited by hand |
| [`audit/TRACKER.md`](audit/TRACKER.md) | Which audit findings each work package carries, the order, and the collision groups | updated when packages are added, split or closed |
| [`audit/`](audit/README.md) (everything else) | The audit of 2026-11-16: summary, findings registers, measurements, tools, interim reference histories | frozen; a record of what was found on that date |
| [`archive/`](archive/) | Pre-audit roadmap, milestone log, question list and superseded decisions | not maintained; nothing in it is a current rule or a source of status |

The live record of work is GitHub: issue `#140` for work packages and issue `#169` for deferred upstream bugs and enhancements. Where a file here and an issue disagree, the issue is current.

Do not add new hand-written status, plan or log files. Status comes from generated artifacts; decisions go in `DECISIONS.md`; everything else goes on the relevant issue.
